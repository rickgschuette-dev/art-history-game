# Art History Game

Browser-based game for eighth graders: Introduction to Art History, Early Medieval Art.

## Status
Prototype. One card (EM-03 Spot the Style) is playable. Seven cards are listed as in development.

## Run locally
Open `index.html` in a browser. No build step.

## Important limits
- The artwork on EM-03 is a layout placeholder. Replace it with the original, rights-cleared manuscript image and verify dimensions before any student testing.
- Progress is saved only in the browser on one device. No accounts, no server.
- Not yet reviewed by an art historian. Not yet reviewed for student-privacy obligations.
- Keyboard use: Tab to the artwork, arrow keys move the cursor, Enter marks.

## Publish
Netlify can publish this folder directly (`netlify.toml`).
